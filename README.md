# Task_mangaement_system

## Description
A task management system to create, prioritize, and track tasks.

## Structure
- backend/ → Flask backend code
- frontend/ → HTML pages
- start_server.bat → To start the server locally

## How to Run
1. Install requirements: `pip install -r backend/requirements.txt`
2. Run `start_server.bat` or `python backend/app.py`
3. Open browser at `http://127.0.0.1:5000/`
